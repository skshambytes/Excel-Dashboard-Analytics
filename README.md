# 📊 Excel Dashboard Analytics

An interactive Excel dashboard designed to analyze sales transactions, product performance, customer demographics, order channels, and delivery efficiency. This project uses Excel's data analysis and visualization capabilities to transform raw transaction data into meaningful business insights.

## 📌 Project Overview

The objective of this project is to analyze transactional data and develop an interactive dashboard that helps stakeholders monitor key performance indicators (KPIs), identify trends, and understand customer purchasing behavior.

The dashboard combines KPI cards, PivotTables, charts, and interactive filtering to present business performance in a clear and accessible format.

## 🎯 Business Objectives

- Monitor overall order volume and sales revenue.
- Analyze product-wise sales and quantity performance.
- Understand customer demographics and purchasing patterns.
- Compare order channels such as App, Website, Instagram, Partner App, and Target.com.
- Evaluate customer ratings and delivery efficiency.
- Explore geographical variations in sales and order quantities.
- Identify trends in transaction volume over time.

## 📂 Dataset Overview

The workbook contains **2,400 transaction records** with fields covering orders, products, customers, sales amounts, ratings, delivery times, and geographic information.

| Column | Description |
|---|---|
| TX ID | Unique transaction identifier |
| Product | Product purchased |
| Quantity | Number of units purchased |
| Unit Price | Price per unit |
| Amount | Total transaction amount |
| Order Date | Date the order was placed |
| Ship Date | Date the order was shipped |
| Customer Gender | Customer gender information |
| Order Mode | Channel through which the order was placed |
| Rating C | Customer rating |
| State | State associated with the transaction |
| County | County associated with the transaction |
| Days to Deliver | Delivery duration in days |
| Weeknum | Week number associated with the order |

## 🔍 Dashboard Analysis

- Track total transaction value and quantity sold.

- Identify products contributing to overall sales.

### 2. Product Analysis
- Analyze quantity sold by product category.
- Compare product demand across customer segments.
- Identify products with higher and lower sales volumes.

### 3. Customer Analysis
- Examine transaction patterns by customer gender.
- Compare customer purchasing behavior across product categories.
- Explore the distribution of customer ratings.

### 4. Order Channel Analysis
- Compare orders placed through different sales channels.
- Analyze channel-level sales contribution.
- Understand how customers interact with different ordering platforms.

### 5. Delivery Performance
- Monitor average delivery time.
- Analyze delivery duration across transactions.
- Evaluate customer ratings alongside operational performance.

### 6. Time-Based Analysis
- Explore order trends across weeks and months.
- Compare transaction volumes over time.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Excel Dashboard.xlsx` in Microsoft Excel.
3. Navigate to the **dashboard** worksheet.
4. Use the available interactive filters or slicers to explore the data.
5. Review the supporting PivotTables for detailed analysis.

**Note:** For the best experience, use a desktop version of Microsoft Excel that supports the workbook's charts, PivotTables, and slicers.
